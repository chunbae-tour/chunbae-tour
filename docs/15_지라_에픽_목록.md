```
Epic Name : [QR Pay] QR 결제 도메인
Summary   : QR 결제 요청 생성 + 상인 승인/거절 (분산 락) + 만료 스케줄러
Labels    : backend, mvp, payment, concurrency
Priority  : Highest
```

**Description (Jira 본문 복붙)**
```
사용자 QR 결제 요청 → 상인 승인 → 엽전 원자적 이전 전체 플로우 구현.

포함 스토리:
- STORY-13: QR 결제 요청 생성 (사용자 측) (5 SP)
- STORY-14: QR 결제 승인/거절 (상인 측, 6단계 트랜잭션 + 분산 락) (13 SP)
- STORY-15: QR 결제 만료 스케줄러 (3 SP)

총 SP: 21
```
