# 06-TASK-CHECKLISTS.md

## 공통 체크리스트

- 현재 브랜치를 확인했는가?
- 변경 파일 목록을 확인했는가?
- 보호 파일을 수정하지 않았는가?
- secret이 포함되지 않았는가?
- 사용자 변경사항을 되돌리지 않았는가?
- 필요한 검증 명령을 실행했는가?

## Docker 작업 체크리스트

- `.env.example`이 최신인가?
- `.env`가 커밋 대상에서 제외되는가?
- 포트는 환경변수로 조정 가능한가?
- MySQL, Redis 포트가 앱 설정과 일치하는가?
- `docker compose config`가 통과하는가?
- `docker compose ps`에서 컨테이너가 정상 상태인가?
- 포트 충돌 시 사용자가 `.env`만 수정하면 되는가?

## Spring Boot 작업 체크리스트

- `./gradlew compileJava`가 통과하는가?
- 필요한 경우 `./gradlew test`를 실행했는가?
- 예외 처리가 구체적인가?
- secret 하드코딩이 없는가?
- 트랜잭션 범위가 과도하지 않은가?
- N+1 가능성을 확인했는가?

## 문서 작업 체크리스트

- 문서가 실제 파일 상태와 일치하는가?
- 명령어가 Windows, macOS, Linux에서 이해 가능한가?
- 깨진 인코딩이 없는가?
- README와 중복되는 내용은 필요한 만큼만 유지했는가?

## PR 전 체크리스트

- base 브랜치가 올바른가?
- PR 제목이 컨벤션을 따르는가?
- 보호 파일 변경 이유를 설명했는가?
- 테스트 결과를 본문에 적었는가?
- PR을 merge하지 않았는가?
- PR URL을 사용자에게 보고했는가?

## 보안 체크리스트

- secret이 코드에 포함되지 않았는가?
- `.env`가 커밋되지 않았는가?
- 사용자 입력이 HTML로 직접 출력되지 않는가?
- 인증, 권한 변경은 승인받았는가?
- 외부 API key 사용은 환경변수 기반인가?
