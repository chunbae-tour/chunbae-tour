## Docker 포트 충돌

- 날짜: 2026-05-12
- 증상: MySQL 컨테이너 실행 시 `port is already allocated` 오류 발생
- 원인: 로컬에서 `3307` 포트를 이미 다른 프로세스 또는 Docker 포워딩이 사용 중
- 해결: `.env`에서 `DB_PORT`를 다른 포트로 변경
- 재발 방지: Docker Compose와 Spring 설정 모두 `DB_PORT` 환경변수를 사용하도록 유지

## 인코딩 깨짐

- 날짜: 2026-05-12
- 증상: PowerShell 출력에서 한글 문서가 깨져 보임
- 원인: 터미널 출력 인코딩과 파일 인코딩이 맞지 않음
- 해결: UTF-8로 파일을 읽거나 IDE에서 UTF-8로 확인
- 재발 방지: 문서 파일은 UTF-8로 저장하고, 깨진 상태로 커밋하지 않음
