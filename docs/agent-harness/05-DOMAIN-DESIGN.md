# 05-DOMAIN-DESIGN.md

이 문서는 도메인, DB, Entity 관련 작업에서 읽는다.

현재 프로젝트는 초기 세팅 단계이므로 상세 도메인 설계는 아직 고정되지 않았다.
도메인 설계가 확정되면 이 문서에 기록한다.

## 현재 고정된 기술 결정

- Java 21 사용
- Spring Boot 4.0.6 사용
- Gradle 사용
- MySQL 사용
- Redis 사용
- 패키지명은 `com.chunbaetour`

## DB 변경 원칙

사용자 승인 없이 다음 작업을 하지 않는다.

- Entity 추가
- Entity 필드 추가, 삭제, 타입 변경
- 테이블명 변경
- 컬럼명 변경
- 인덱스 추가 또는 삭제
- 마이그레이션 방식 변경

DB 변경이 필요하면 먼저 다음을 보고한다.

- 변경 목적
- 영향받는 Entity
- 예상 테이블 변경
- 기존 데이터 영향
- 필요한 테스트

## Repository 작업 원칙

- N+1 가능성을 확인한다.
- 조회 조건이 많아지면 명확한 메서드명 또는 쿼리 방식을 사용한다.
- 페이징이 필요한 목록 조회는 처음부터 페이징을 고려한다.
